# ORCHID tutorials

Thirteen notebooks cover one section of ORCHID each. Every notebook has learning goals, the theory with
equations, runnable examples (stored with their outputs), exercises with hidden solutions, and a
five-question quiz.

| # | Tutorial | Modules |
|---|---|---|
| 01 | [Hopping rates and energetic disorder](01_rates_and_disorder.ipynb) | `rates`, `lattice` |
| 02 | [Kinetic Monte Carlo: mobility, TOF and relaxation](02_kinetic_monte_carlo.ipynb) | `kmc` |
| 03 | [Master equation and the EGDM](03_master_equation_egdm.ipynb) | `master_equation`, `models` |
| 04 | [Drift-diffusion: diodes, solar cells and OLEDs](04_drift_diffusion.ipynb) | `drift_diffusion`, `devices` |
| 05 | [Transients and small-signal analysis](05_transients_smallsignal.ipynb) | `transient`, `smallsignal` |
| 06 | [2D drift-diffusion and OFETs](06_dd2d_ofet.ipynb) | `dd2d` |
| 07 | [Optics: transfer matrices, generation and outcoupling](07_optics.ipynb) | `optics`, `materials` |
| 08 | [Excitons: diffusion, annihilation and quenching](08_excitons.ipynb) | `exciton`, `exciton_device` |
| 09 | [3D device KMC with concurrent excitons](09_device_kmc_coupled.ipynb) | `device_kmc`, `coupled_kmc` |
| 10 | [Morphology, DFT couplings and MD trajectories](10_morphology_md.ipynb) | `morphology` |
| 11 | [Exhaustive search, ML surrogates and Bayesian inversion](11_search_ml_bayes.ipynb) | `search`, `ml` |
| 12 | [Massive parallelism: MPI, threads, GPU and sublattice KMC](12_parallel_gpu.ipynb) | `parallel`, `gpu`, `sublattice_kmc` |
| 13 | [Benchmarking and validation](13_benchmarking.ipynb) | `validation/` |

## Running

```bash
pip install -e ".[dev,qc]" jupyter
jupyter lab docs/tutorials
```

The notebooks are small enough to run on a laptop: each takes one to a few minutes.

## Quizzes

```bash
orchid quiz          # pick a section
orchid quiz 04       # drift-diffusion quiz
```

```python
from orchid.tutorials import quiz
quiz("04")                    # show
quiz("04", answers="abcda")   # grade
```

The question bank (65 questions) is in `orchid/data/quizzes.json` and is generated from `tools/make_quizzes.py`.
The notebooks are generated by `tools/build_tutorials.py --execute`.
